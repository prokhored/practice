Отчет по практике должен состоять из двух частей (глав). Первая глава включает в себя проектирование и анализ функций разрабатываемого приложения/модуля приложения, вторая глава практическая – включает в себя процесс разработки и минимального тестирования приложения/его модулей. 
За время практики необходимо:
    1) Найти готовое веб-приложение (сайт), написанное с использованием следующего технологического стека: html, css, js (frontend). Приложения можно брать только из открытых источников - с GitHub.
    2) Развернуть данное приложение на ПК, проверить его работоспособность.
    3) Смоделировать будущие модули приложения с помощью языка моделирования UML (диаграмма вариантов использования).
    4) Произвести моделирование функций приложения с использованием методологии SADT. (нотация IDEF0, декомпозиция до 2 или до 3 уровня) ИЛИ диаграмма деятельности UML.
    5) Дописать к этому приложению несколько функций (функции должны каким-либо образом взаимодействовать с БД mySQL – БД должна храниться в облаке (filess.io)). Основные функции – модуль регистрации/авторизации с шифрованием паролей, система сессий пользователей (какие-то действия будут доступны только авторизированным пользователям) + еще одна дополнительная (к примеру, обратная связь с пользователем или любую другая необходимая найденному приложению). 
    6) Протестировать разработанный модуль.
    7) Сделать выводы по результатам работы.
    8) Изначальная версия проекта должна быть загружена на github и названа «первая версия проекта», затем доделанная/измененная версия проекта должна быть снова загружена на github и названа «итоговая версия проекта».

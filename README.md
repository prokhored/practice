# Деплой на Vercel

## Настройка проекта

1. Импортируйте репозиторий в Vercel.
2. Для `Framework Preset` выберите **Other**.
3. Оставьте Build Command пустой, а Root Directory — корень проекта.
4. В настройках проекта добавьте переменные окружения из `.env.example`.
5. Для `NODE_ENV` используйте значение `production`.

Vercel использует `api/index.js` как serverless-функцию. Файл `server.js` по-прежнему можно запускать локально командой `npm run dev`.

## Важно

- База данных не создаётся и не изменяется при деплое. Укажите доступ к уже существующей MariaDB в переменных `host`, `user`, `password` и `database`.
- Файлы видео продолжают отправляться на VDS через SFTP. Для этого нужны `sftpHost`, `sftpUsername`, `sftpPassword` и `videoBaseUrl`.
- В Vercel файловая система временная, поэтому локальная папка загрузок используется только как временное хранилище перед отправкой на VDS.
- Ограничения Vercel на размер входящего запроса применяются к загрузке видео. Для больших файлов используйте загрузку непосредственно на VDS или увеличьте лимит/выберите подходящий тариф Vercel.
- Не добавляйте `.env` в репозиторий. Он уже исключён через `.gitignore`.
